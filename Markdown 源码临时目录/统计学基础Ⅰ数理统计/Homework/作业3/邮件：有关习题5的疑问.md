**原题如下：** 
设随机变量 $X$ 均值有限，$0<p<1$  
证明随机变量 $X$ 的 $p$-分位数 $\zeta_p$ 满足 $\zeta_p = \underset{a}{\text{argmin}}\ \text{E}[p\cdot(X-a)_+ + (1-p)\cdot (X-a)_- ]$   
其中 $(c)_+ = \max(c,0),\ (c)_- = \min(c,0)$  

**我尝试在增添 $X\sim \text{Uniform}(0,1)$ 的假设下验证这个结论，但是失败了：**  

- 定义目标函数:   
  $\begin{align}
  L(a) 
  &= \text{E}[p\cdot \max\{0,X-a\}+(1-p)\cdot \min\{0,X-a\}]\\
  &= p\int_a^1(x-a)dx + (1-p)\int_0^a (x-a)dx\\
  &= p(\frac12 - a + \frac{a^2}{2}) + (1-p)(-\frac{a^2}2)\\
  &= (p-\frac12) a^2 - pa -\frac{p}{2}\end{align}$   

  我想要验证 $\text{argmin}\ L(a)$ 对于任意 $p\in [0,1]$ 是否都等于 $X\sim \text{Uniform}(0,1)$ 的 $p$-分位数 $p$.

  对 $a$ 求导得到:  
  $L'(a) = (2p-1)a - p$   
  很容易找到一种情况，使得 $\text{argmin}\ L(a)\neq p$   
  例如当 $p = \frac{3}{4}$ 时，$L'(a) = 0$ 的解是 $a^\star = 2p = \frac{3}{2}$  
  这个零点 $a^\star$ 确实是 $L(a)$ 的极小值点，但它并不是 $X\sim \text{Uniform}(0,1)$ 的 $\frac34$ 分位数.



我觉得也许应该把 $\zeta_p = \underset{a}{\text{argmin}}\ \text{E}[p\cdot(X-a)_+ + (1-p)\cdot (X-a)_- ]$ 中的 $+$ 改成 $-$，  
即改成 $\zeta_p = \underset{a}{\text{argmin}}\ \text{E}[p\cdot(X-a)_+ - (1-p)\cdot (X-a)_- ]$   
**下面是修改后的题目在假设 $X$ 为连续随机变量的条件下的简化证明：**      
设随机变量 $X$ 均值有限，$0<p<1$  
证明随机变量 $X$ 的 $p$-分位数 $\zeta_p$ 满足 $\zeta_p = \underset{a}{\text{argmin}}\ \text{E}[p\cdot(X-a)_+ - (1-p)\cdot (X-a)_- ]$   
其中 $(c)_+ = \max(c,0),\ (c)_- = \min(c,0)$  

- **证明：**  
  为简单起见，我们假设 $X$ 是连续随机变量，具有累积分布函数 $F$ 和概率密度函数 $f$   
  我们定义目标函数为：  
  $\begin{align}
  L(a) 
  &\overset{\Delta}=  
  \text{E}[p\cdot(X-a)_+ - (1-p)\cdot (X-a)_- ]\\
  &=
  p\int_a^\infty (x-a)f(x)dx - (1-p)\int_{-\infty}^{a} (x-a) f(x)dx\end{align}$  
  - **引理：(Leibniz 积分规则)**    
    变限积分 $\int_{g(a)}^{h(a)}F(x,a)dx$ 关于 $a$ 的导数为：  
    $\frac{d}{da}\int_{g(a)}^{h(a)}F(x,a)dx
    = \int_{g(a)}^{h(a)}\frac{\partial}{\partial a}F(x,a)dx + F(h(a),a)h'(a) -F(g(a),a)g'(a)$​     
  - **应用引理：**  
    我们知道 $\begin{cases}
    \frac{d}{da}\int_a^\infty (x-a)f(x)dx 
    = -\int_a^\infty f(x)dx = F(a)-1\\
    \frac{d}{da}\int_{-\infty}^{a} (x-a) f(x)dx 
    = -\int_{-\infty}^{a} f(x)dx = -F(a)\end{cases}$  
    于是我们有 $\frac{\partial}{\partial a}L(a) = p[F(a)-1] + (1-p)F(a) = F(a)-p$   
    记其**零点集**为 $\mathcal A^\star = \{a:F(a) = p\}$ (显然不为空集)  
    根据 $F$ 的单调性可知 $\frac{dL}{da}$ 关于 $a$ (非严格) 单调递增，  
    因此目标函数 $L(a)$ 在 $a\in \mathcal A^\star$ 处取得最小值.  
    于是有：  
    $\begin{align}
    \zeta_p 
    &= \underset{a}{\text{argmin}}\ L(a) \\
    &= \inf\{a:a\in \mathcal A^\star\}\\
    &= \inf\{a:F(a) = p\}\\
    &= \inf\{a:F(a)\geq p\}\\
    &= F^{-1}(p)\end{align}$  
    根据本次作业第三题的结论 (其中 $F^{-1}(p)=\inf\{a:F(a)\geq p\}$ 为**分位函数**)，  
    我们知道 $\zeta_p$ 满足 $F(\underset{\varepsilon\to 0^+}{\lim}\{\zeta_p - \varepsilon\})\leq p\leq F(\zeta_p)$，即 $\zeta_p$ 是 $p$-分位数.
